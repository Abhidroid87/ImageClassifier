# ImageClassifier Local Trainer

This Space is a static browser application. Dataset decoding, training, metrics, and inference run in the visitor's browser. The Space does not receive the user's image dataset.

TensorFlow.js uses WebGPU when available and falls back to another browser backend. ONNX Runtime Web is available for inference with compatible exported models.
